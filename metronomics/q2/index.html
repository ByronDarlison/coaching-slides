darlison.com

At a quarterly, the six levers are the check on the KFFM. The KFFM is only right if the team is using it to move more cash faster.

The team’s own KFFM is on the board or printed. This drawing names the levers. Go lever by lever. For each one, ask its owner what they did to push it last quarter and what moved. A lever nobody is pushing is a finding. Write it down.

Quantity and conversion: work from the end of the flow back to the start. Every hand-off has a named widget. Each widget is countable, and it is not revenue or cash. Its owner controls it and counts it every week. These are the widgets the team forecasts week by week in the sprint lanes.

Price: what price did customers pay? What changed when you raised it?

Timing: add the days each function really took last quarter. Where did the work wait? Which function added the most days? Compare with the days the team estimated last time.

Capacity is how many widgets a function can handle in a month. A function can be fast and still too small.

Cost: what each function costs to run.

Each critical number should tell the owner whether the function is working. It moves when the work gets better or worse, and its owner looks at it every day. Keep one critical number for each function. Focus the discussion on at most 4.

Profit per X: has a good one emerged? If not, leave it blank. X is usually a widget from the KFFM.
