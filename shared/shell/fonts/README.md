# Shared slideshow fonts

These files are the same Geist bundle as the cash deck.

- `geist-latin.woff2` is Geist Sans for titles and body text.
- `geist-mono-latin.woff2` is Geist Mono for labels and navigation.

Copy this folder with the deck.

The deck loads these files from disk.

Do not load fonts from a network.

The license text is in `LICENSE.txt`.

The cash copy lives in `eoa-cash/deck/assets/fonts/`.
